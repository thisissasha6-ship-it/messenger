# Мессенджер (интерфейс как у Telegram) на Supabase

Регистрация, личные чаты, картинки (просмотр и скачивание), аудио- и видеозвонки.
Сервер не нужен: всё хранится в Supabase (адрес и ключ уже прописаны в www/index.html).

## Сборка APK
1. Загрузите файлы в репозиторий GitHub (папка .github обязательна).
2. Вкладка Actions, затем Build APK, затем Run workflow.
3. Через 5-10 минут скачайте messenger-apk из раздела Artifacts и установите app-debug.apk.

## Звонки между мобильными сетями
Нужен TURN-сервер. Впишите его данные в константу TURN в начале скрипта www/index.html.

## Ограничения
- Звонок приходит, только пока приложение открыто.
- Только личные чаты.
- Если проект Supabase неделю не используется, он засыпает (включается кнопкой в панели).
