# Мессенджер (копия интерфейса Telegram)

Регистрация, личные чаты, картинки (просмотр и скачивание), аудио- и видеозвонки.

## 1. Запустить сервер (бесплатно)

Нужен Node.js 18+.

```
npm install
npm start
```

Сервер стартует на порту 3000, сайт-версия открывается в браузере. Данные хранятся в папке `data/`.

Чтобы телефоны достучались до сервера, он должен быть доступен из интернета. Бесплатные варианты:

- **Свой компьютер + Cloudflare Tunnel.** Скачайте `cloudflared` и выполните `cloudflared tunnel --url http://localhost:3000`. Получите бесплатный https-адрес. Минус: адрес меняется при каждом перезапуске, компьютер должен быть включён.
- **Oracle Cloud Always Free.** Бесплатная виртуальная машина навсегда, работает 24/7 (нужна банковская карта для проверки, деньги не списываются). Лучший вариант для постоянной работы.
- **Render / Railway (бесплатный тариф).** Проще всего, но сервер засыпает, а файлы и база могут стираться при перезапуске.

## 2. Собрать APK (бесплатно)

1. Создайте репозиторий на GitHub и загрузите туда все файлы проекта.
2. Вкладка **Actions → Build APK → Run workflow**.
3. Через несколько минут скачайте `messenger-apk` из раздела Artifacts, распакуйте и установите `app-debug.apk` на телефон (разрешите установку из неизвестных источников).
4. При первом входе в приложении укажите адрес вашего сервера.

## 3. Звонки через мобильную сеть

Звонки работают через WebRTC. В одной Wi-Fi сети всё работает сразу. Между разными мобильными сетями часто нужен TURN-сервер. Бесплатно: поставьте `coturn` на ту же виртуальную машину или зарегистрируйтесь в бесплатном сервисе вроде Metered Open Relay. Затем запустите сервер с переменными:

```
TURN_URL=turn:адрес:3478 TURN_USER=логин TURN_PASS=пароль npm start
```

## Ограничения

- Звонок приходит, только пока приложение открыто (для фоновых уведомлений нужен Firebase Cloud Messaging).
- Только личные чаты, без групп.
- Картинки хранятся на сервере по случайным ссылкам (любой, у кого есть ссылка, может открыть картинку).
- APK собирается в debug-режиме: годится для установки на свой телефон, но не для Google Play.
